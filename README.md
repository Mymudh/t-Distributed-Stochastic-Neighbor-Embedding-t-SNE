# t-Distributed Stochastic Neighbor Embedding (t-SNE)

A Python-based machine learning project for visualizing high-dimensional data using t-SNE dimensionality reduction.

## Technologies Used

- Python
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## Objective

To reduce high-dimensional data into a 2D representation and visualize patterns, relationships, and clusters within the dataset.

## Method

The project applies preprocessing and t-SNE dimensionality reduction to transform high-dimensional features into a 2D space for visualization and analysis.
